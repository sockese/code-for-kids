LABO CODE — programmer, explorer, décoder
=========================================

Pour jouer : ouvrir l'adresse du site (ou « index.html ») dans Chrome, Edge ou Firefox.
Sur tablette Android : Chrome → menu ⋮ → « Installer l'application » (fonctionne ensuite hors ligne).

Parcours : écran d'arrivée → choix du prénom + avatar (pas de mot de passe) → hub avec 3 activités.
La progression est sauvegardée dans le navigateur, par prénom. Points et rang communs aux 3 activités.

ACTIVITÉS
- 🐢 Tortue — Dessins : 75 niveaux en 8 séries (A à H) + mode création libre. Blocs Blockly en français.
- 🧭 Tortue — Labyrinthes : 12 niveaux (avancer, tourner, répéter, répéter jusqu'à l'arrivée, si / sinon, fraises).
- 🕵️ Agence Z : 36 missions en 6 séries (symboles, César, binaire, texte en binaire, morse/miroir/grille,
  opérations spéciales) + dossier secret (histoire), grades, insignes, et « Courrier » pour échanger des
  messages codés avec un ami par copier-coller (rien n'est envoyé sur Internet).

Pour les adultes : boutons « Solution » dans chaque niveau / mission. Page de test automatique : #test
(ex. https://sockese.github.io/tortue-blocs/#test).

Fichiers
  SPEC*.md          les spécifications
  DEPLOIEMENT.md    installation sur tablette Android (mode appli, hors ligne)
